# CSV Active Status Generator

This Python script helps you generate and manage CSV files containing activation status information.

## Features

- Generate CSV files with activation status
- Check and update activation status
- Easy-to-use Python implementation

## Requirements

- Python 3.x
- pandas (install using `pip install pandas`)

## Usage

1. Clone this repository
2. Install required dependencies
3. Run the script:

```python
python active_status.py
```

## Example Output

The generated CSV will contain:
- ID
- Name
- Status
- Timestamp
